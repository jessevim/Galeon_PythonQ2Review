1. Functions, Parameters, Arguments, Return

A function is a named block that does one task. Breaking a problem into functions is decomposition: a fuel-efficiency program becomes get_distance(), get_fuel_used(), calculate_efficiency(), display_result(). Benefits: readability, reusability, easier debugging and testing, easier improvement, collaboration.

def create_greeting(name):      # definition: name = PARAMETER
    message = "Hello, " + name + "!"   # body (indented)
    return message                      # sends a value back

result = create_greeting("Ana") # call: "Ana" = ARGUMENT
print(result)
Parameter = placeholder in the definition. Argument = real value in the call. Definition creates the function (nothing runs yet); the call runs it.

Try it: call a function





return vs print: print only shows text. return hands a value back so you can store it, compare it, or reuse it. A function without return gives back None, so total = add(4,7) would store None.

    return score >= 75

2. Iterative Structures (Loops)


Loops repeat code. Use for when the count is known; use while when repetition depends on a condition that changes at runtime. Both rely on the same conditions you used in if.


for + range(start, stop, step)


stop is excluded; start defaults to 0 and step to 1; a negative step counts down.







break stops the whole loop. continue skips only the current pass. In nested loops they affect only the inner loop.


while: input validation


p = input("Enter the password: ")
while p != "password123":
    print("Password is incorrect. Please try again.")
    p = input("Enter the password: ")
print("You can now continue using this program.")


Ground-up logic: (1) ask once, (2) test the condition, (3) the body must change the tested variable (re-ask), otherwise you get an infinite loop. Python also allows while ... else, where else runs when the condition turns false (not when break is used).

3. Arrays (Lists in Python)


A list stores many values under one name. Each item has an index starting at 0. Python lists can grow and mix types, so you can append, insert and remove items freely.


items = ["Notebook", "Pen", "Calculator", "Laptop", "Book"]
print(items[2])     # Calculator
for i in range(len(items)):   # traversal by index
    print("Element at index", i, ":", items[i])
print(items[1:4])   # slice: start included, end excluded

4. Strings, Date and Time


A library is prewritten code (a toolbox); a method belongs to a data type, such as "text".strip(). User input is messy, so clean it: name.strip().title(). Chaining works left to right.




Dates are objects, not text, so Python handles leap years and month lengths. strftime formats them, strptime parses text, timedelta does date arithmetic.


from datetime import datetime, date, timedelta
d = datetime(2026, 6, 3)
print(d.strftime("%B %d, %Y"))   # %B month name, %d day (zero-padded), %Y 4-digit year
print(d.strftime("%A"))          # weekday

# Days until a deadline: define BOTH dates first
today = date(2026, 5, 22)          # use date.today() for the real current date
deadline = date(2026, 6, 3)
days_left = (deadline - today).days
print("Days remaining:", days_left)

# Parse text into a date, then do date arithmetic
parsed = datetime.strptime("2026-06-03", "%Y-%m-%d").date()
print(parsed == deadline)
print(today + timedelta(days=7))   # one week after today




Note: %d gives 03, not 3. The guide shows "June 3, 2026" as a sample; to match it exactly, use f"{d.strftime('%B')} {d.day}, {d.year}".

A. Modular Calculator (Guide 1)


Decompose: get numbers, choose operation, compute, display. One function per operation, each taking parameters and returning a value. Guard division by zero by returning None, and let the caller decide what to print.


def add(a, b):
    return a + b
def subtract(a, b):
    return a - b
def multiply(a, b):
    return a * b
def divide(a, b):
    if b == 0:
        return None
    return a / b
def calculate(op, a, b):       # decides which function to call
    if op == "+": return add(a, b)
    elif op == "-": return subtract(a, b)
    elif op == "*": return multiply(a, b)
    elif op == "/": return divide(a, b)
result = calculate("/", 10, 4)
if result is None:
    print("Cannot divide by zero")
else:
    print("Result:", result)

C. Deadline and Date Formatter (Guide 4, Activity 2)

from datetime import datetime
title = input("Enter event title: ").strip()
y, m, d = int(input("Year: ")), int(input("Month: ")), int(input("Day: "))

    when = datetime(y, m, d)

    print("Weekday:", when.strftime("%A"))

Problem 1: Sum of Numbers (for loop)


Plan: (1) get a positive whole number; (2) getSum(limit) keeps a running total = 0 and adds each i from 1 to limit; (3) compare with the formula n(n+1)/2. isdigit() rejects "-5" and "abc" (no minus sign, no letters); > 0 rejects zero. range(1, limit + 1) because stop is excluded. Use // so the expected value stays an integer.


def getSum(limit):
    total = 0
    for i in range(1, limit + 1):
        total += i
    return total

def get_positive(prompt):
    while True:
        text = input(prompt)
        if text.isdigit() and int(text) > 0:
            return int(text)
        print("Invalid input.")
        print("Please enter a positive whole number.")

n = get_positive("Hi there! Please enter your age: ")
expected = n * (n + 1) // 2
print("Expected sum is", expected)
result = getSum(n)
print("After calling the function getSum, the sum of all numbers from 1 to", n, "is:", result)
if result == expected:
    print("Output Verified")
else:
    print("Output verification failed")


  


Problem 2: Password Validation (while + break)


Plan: while True is intentional: we do not know how many tries it takes, and break is the only exit. Order of checks matters: blank first (invalid input), then match (success and break), otherwise wrong. Comparison with == is case-sensitive, so "Admin123" fails.


def checkPassword(correctPassword):
    while True:
        entered = input("Enter password: ")
        if entered.strip() == "":
            print("Invalid input. Password cannot be blank.")
            continue                      # ask again
        if entered == correctPassword:
            print("Access granted.")
            break                         # leave the loop
        print("Incorrect password.")
    print("Output verified.")

checkPassword("admin123")


  


Problem 3: Number Patterns (nested loops)


Plan: outer loop = rows, inner loop = columns printing the column number with end="", then print() ends the line. Per the hint, count rows in the outer loop and columns in the inner loop. Reset the column counter at the start of every row, otherwise it would equal rows x columns. Note: the guide writes Else with a capital E; Python needs lowercase else.


def verifyPattern(generatedRows, generatedColumns, rows, columns):
    if generatedRows == rows and generatedColumns == columns:
        print("Pattern verified.")
    else:
        print("Pattern verification failed.")

def displayPattern(rows, columns):
    generatedRows = 0
    generatedColumns = 0
    for r in range(1, rows + 1):
        generatedRows += 1
        generatedColumns = 0              # reset for each row
        for c in range(1, columns + 1):
            print(c, end="")
            generatedColumns += 1
        print()
    print("Generated rows:", generatedRows)
    print("Generated columns:", generatedColumns)
    verifyPattern(generatedRows, generatedColumns, rows, columns)

def get_positive(label):
    while True:
        text = input("Enter number of " + label.lower() + ": ")
        if text.isdigit() and int(text) > 0:
            return int(text)
        print("Invalid input.", label, "must be a positive whole number.")

rows = get_positive("Rows")
columns = get_positive("Columns")
displayPattern(rows, columns)


  


Problem 4: Skipping Multiples (continue)


Plan: test n % 3 == 0 (remainder 0 means multiple of 3). When true, count it and continue so the print line is skipped for that pass only. Expected count is limit // 3, an independent calculation, so a match proves the loop skipped exactly the right numbers. The sample text says skippedMultiples but the required name is skipMultiples; follow the problem statement.


def verifyOutput(skippedCount, expectedSkippedCount):
    if skippedCount == expectedSkippedCount:
        print("Output verified.")
    else:
        print("Output verification failed.")

def skipMultiples(limit):
    skippedCount = 0
    for n in range(1, limit + 1):
        if n % 3 == 0:
            skippedCount += 1
            continue
        print(n, end=" ")
    print()
    return skippedCount

while True:
    text = input("Enter limit: ")
    if text.isdigit() and int(text) > 0:
        limit = int(text)
        break
    print("Invalid input.")
    print("Please enter a positive whole number.")

expectedSkippedCount = limit // 3
print("Expected skipped count is:", expectedSkippedCount)
skipped = skipMultiples(limit)
print("After calling the function skipMultiples, the computed skipped count is:", skipped)
verifyOutput(skipped, expectedSkippedCount)
